## 3. Binding invariants / exclusions

1. Real `.md` file is the source of truth. User/agent/external edits affect real file (with bounded debounce and CAS); `md_temp` is only last accepted snapshot. Ctrl+S copies the *current raw bytes* to `md_temp`; partial Accept changes exactly the accepted hunk there; Undo/Restore edits real file under CAS. Never normalize unrelated bytes (BOM, CRLF/LF mixture, no final newline, comments, tables, CJK). Preserve conflicted drafts rather than overwriting stale file.
2. One canonical diff/revision contract, projections only in Preview/Source/ProseMirror. Decorations never serialize into Markdown. Mapping must be deterministic (source byte offsets + unique node/image identity and revision), otherwise fail visibly and refuse write rather than guess duplicate paragraph/image/cell.
3. Source editor must avoid O(document-lines) DOM rebuild on each keystroke; measure 900/5,500 lines, 500 KB/5 MB, CJK/IME, key input→paint p95, long tasks, DOM mutations, browser navigation, writes, checksum and CAS. 5,500-line p95 **<40 ms**, no full backdrop rebuild; 500KB/5MB limits determined from POC versus approved upstream reference. No long-debounce masking or disabling diff as the fix.
