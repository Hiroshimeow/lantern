# Checklist Chức Năng Nền Tảng — Lantern `v8.2` Baseline

Mọi phiên bản Lantern (`v8.2`, `v9.0`, `v9.21`, `v9.22+`) đều phải đảm bảo không bị suy giảm (degrade) các chức năng nền tảng sau khi kiểm tra qua CDP:

- [x] **`BASE_01` — Folder Explorer & Chọn File Như Người Thật**:
  - Mở trang chủ `/`, hiển thị danh sách thư mục và file (`.grid`, `.card` hoặc bảng file).
  - Người dùng click chuột vào ô chọn file (`.select-check` / `input[type="checkbox"]`) hoạt động chính xác.
- [x] **`BASE_02` — Thanh Công Cụ Phụ Trợ Markdown (`🕒 Version`, `🖼️ Images OK`, `🗜️ Zip`, `⌨️ Terminal`)**:
  - Trên trang xem Markdown (`/api/plugin/preview?p=...`), hiển thị đầy đủ nút lịch sử phiên bản `#mdVersionDiffBtn`, kiểm toán ảnh `#mdImageAuditBadge`, đóng gói `#mdArchiveZipBtn`, và bật tắt `#mdTerminalBtn`.
- [x] **`BASE_03` — Cô Lập Phiên Giữa Nhiều Tab Trình Duyệt (Multi-Tab Isolation)**:
  - Mở 2 tab trình duyệt khác nhau cùng trỏ vào Lantern, mỗi tab có `clientSessionId` độc lập trong `sessionStorage` / `window.name` và `0` lỗi HTTP 5xx / JS Exception.
