# Checklist Tính Năng & Chống Suy Giảm — Lantern v9.25 (`v9.25_release.md`)

Bản **v9.25** tập trung nâng cấp toàn diện hệ thống **Lantern Gallery & Windows-Grade File Explorer** (tách sạch kiến trúc mô-đun, bổ sung cây thư mục kiểu Windows Explorer, nâng cấp cơ chế tải ảnh/video/file nặng và kiểm chứng tự động bằng CI + Chromium thực tế).

## 1. Kiến Trúc Mô-Đun Sạch (Không Super-File, Không Xé Lẻ Quá Mức)
- [x] Rút gọn `lantern/views.py` từ **1.046 dòng** (nhúng CSS/JS inline trong chuỗi Python) xuống **~130 dòng** Python thuần.
- [x] Tách giao diện Gallery/Explorer thành 5 module rõ trách nhiệm:
  - `static/gallery.css`: Hệ giao diện Windows Explorer 3 khung (Tree + Canvas + Preview Pane + Status Bar).
  - `static/gallery_tree.js`: Cây thư mục lazy-load kiểu Windows, kéo thay đổi độ rộng, nhận kéo-thả Move/Copy/Upload.
  - `static/gallery_upload.js`: Bộ quản lý Upload đa luồng không chặn, tự động chia khối 16 MiB cho file nặng (`>= 32 MiB`), Pause/Resume/Retry, thanh tiến trình nổi nền.
  - `static/gallery_media.js`: Lightbox xem ảnh/video mượt (Zoom/Pan/Rotate/Fullscreen, preload ±2 ảnh, chọn tốc độ video, phụ đề, giữ nguyên Crop).
  - `static/gallery_app.js`: Điều hướng SPA không reload trang, Address Bar gõ đường dẫn, 4 chế độ xem, Clipboard `Ctrl+C/X/V`, phím tắt Explorer, Properties, Telemetry VRAM/CPU/RAM.

## 2. Trải Nghiệm Giống Windows File Explorer & Tốc Độ Cao
- [x] **Cây thư mục (`GET /api/tree`)**: Lazy-load từng nhánh + tải đồng bộ tổ tiên 1 lần (`ancestors=1`), tự mở đến thư mục hiện tại, kéo thả file từ Grid hoặc từ Windows vào thẳng thư mục trên cây.
- [x] **Điều hướng SPA & Address Bar**: Nút `←` / `→` / `↑` / `↻`, phím `Alt+←/→/↑`, `Backspace`, `Ctrl+L` / `Alt+D` để gõ đường dẫn trực tiếp không reload trang.
- [x] **4 chế độ hiển thị hài hòa**: `Large` (Gallery ảnh lớn), `Grid`, `List`, `Details` (bảng cột sắp xếp Name / Date modified / Type / Size) + batched `requestAnimationFrame` render cho thư mục >1.000 file.
- [x] **Clipboard & Phím tắt Windows**: `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Shift+Click` chọn vùng, `Ctrl+A`, `F2` đổi tên, `Delete` xoá, `Space` xem nhanh, `Alt+Enter` xem Properties (`GET /api/properties`).
- [x] **Tìm kiếm tốc độ cao**: Lọc tức thì phía client + lọc đệ quy phía server tự động bỏ qua thư mục rác nặng (`node_modules`, `__pycache__`, `.git`, `.venv`) và giới hạn quét an toàn.

## 3. Tải File Nặng, Ảnh/Video & Sửa Lỗi Degrade
- [x] **Chunked Upload cho file nặng (`>= 32 MiB`)**: `/api/upload/chunk`, `/api/upload/complete`, `/api/upload/abort` với retry từng khối 16 MiB, không chặn thêm file mới khi đang upload, thu gọn thành pill nổi chạy nền.
- [x] **Thumbnail nguyên tử & Cache thông minh**: Khóa theo từng cache key + ghi file tạm `os.replace` chống hỏng JPEG khi tải song song, fallback `-ss 0` cho video ngắn `< 1s`, cache `immutable` cho URL có `?v=`, bật nén `gzip` cho HTML/JS/CSS/JSON và chuẩn `Content-Disposition` RFC 5987 cho tên file tiếng Việt.
- [x] **Chống degrade Telemetry & Delete**: Sửa hiển thị **VRAM / GPU / CPU / RAM** khớp đúng schema camelCase từ `/api/sysstats` và kiểm chứng thao tác **Xoá file/thư mục** trực tiếp trên cả HTTP lẫn trình duyệt Chromium thực tế.
